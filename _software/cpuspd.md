CPUSPD is a DOS utility for throttling CPU speed. On a fast retro build, some DOS games — especially older titles that tie their logic to CPU clock rather than a fixed timer — end up running too fast to be playable rather than too slow. Combined with cache control, tools like CPUSPD bring tricky, clock-sensitive titles back to a sane speed without having to physically slow the machine down.
