STinG is a TCP/IP networking stack for the Atari ST. Getting it running is the software half of getting an ST online at all: once a [NetUSBee]({% link _hardware/atari-st-netusbee-usb-ethernet-adapter.md %}) Ethernet adapter is installed for the hardware side, STinG plus the right TOS drivers is what actually gives the machine a network connection to build a browser or any other networked software on top of.
