Makedisk writes `.ST` and `.MSA` Atari ST disk images to a real floppy disk, run from a DOS prompt. It was written by Darren Birks back in 1997, and it's still the most reliable tool I've found for the job — I run it from a bootable DOS USB drive, since that's the easiest way to get a working DOS environment on a modern PC.
