Glide is [3dfx](https://en.wikipedia.org/wiki/3dfx_Interactive)'s proprietary 3D graphics API, built for its own [Voodoo hardware]({% link _hardware/3dfx.md %}). It was far simpler to target than Direct3D or OpenGL were at the time, which is why a whole generation of late-90s games were written to Glide directly rather than through a general-purpose API — and it's why Voodoo cards are still sought after today: for a lot of those titles, real 3dfx hardware paired with Glide is still the most authentic way to run them.

It's usually thought of as a Windows 98 thing, since Glide's wide support was one of the big reasons to buy a Voodoo card back then, but Glide games are supported in DOS too, including a handful that run [Tomb Raider]({% link _software/tomb-raider.md %})-style titles natively from a DOS prompt rather than through Windows at all.

I keep coming back to it through the [Voodoo 2]({% post_url 2026-08-30-voodoo-2-on-a-modern-pc %}) and [Voodoo 2 in a thin client]({% link _hardware/hp-compaq-t5710.md %}) builds — Glide compatibility is usually the actual test of whether one of these old cards is working properly, more than any benchmark score.
