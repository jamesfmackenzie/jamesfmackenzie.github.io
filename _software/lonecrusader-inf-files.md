[LoneCrusader's Intel chipset INF files](http://lonecrusader.x10host.com/intel_inf.html) are drivers for Intel chipsets that are otherwise too new for [Windows 98]({% link _software/windows-98.md %}) to recognise out of the box. Slipstreamed into the install, they cleared up several unknown devices left sitting in Device Manager on a Dell OptiPlex 380 build — the same install that needed [Rudy Loew's SATA patch]({% link _software/rudy-loew-patches.md %}) just to boot in the first place.
